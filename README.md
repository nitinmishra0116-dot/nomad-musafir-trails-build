# Nomad Musafir Trails — V1.1

A redesigned customer-facing travel platform combining the uploaded visual/content benchmark with the V1 product foundation.

## Design direction
- Dark cinematic editorial identity
- Cormorant Garamond + Manrope
- Obsidian / sand / terracotta / sun / forest palette
- Asymmetric trail cards
- Trail/contour motif
- Story-first copy
- Community and Passport built into the product narrative

## Routes
